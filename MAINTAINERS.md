## Review and release authority

- Changes to the Dockerfile, workflows, pinned tools, or publication metadata require maintainer review.
- Published images must retain SBOM, provenance, and keyless signing.
- Contributors do not receive registry publishing credentials.

## Contributors

Use the repository pull-request process and run the documented image and workflow checks before review.
